# Guitar Chord Sheet App (기타 악보 뷰어 & 에디터)

기타 연주자를 위한 웹 기반의 코드 & 가사 악보 제작 및 열람 애플리케이션입니다.  
ChordPro 포맷 지원, 실시간 조옮김(Transpose), 자동 스크롤, 기타 코드 운지법 다이어그램 등을 지원합니다.

---

## 🎸 주요 기능

1. **ChordPro 악보 뷰어 & 에디터**
   - ChordPro 문법(`[G]동해물과 [D]백두산이`) 완벽 지원
   - 뷰어에서 가사와 코드가 정확히 1:1로 정렬되어 화면 크기가 변해도 코드가 밀리지 않음
   - **🪄 AI 악보 자동 생성기 (Google Gemini AI)**: 노래 제목과 가수명만 입력하면 AI가 원곡 키, 추천 카포, BPM, 가사+코드를 3초 만에 자동 작성
   - 빠른 코드 입력 툴바 (C, D, Em, F, G, Am 등 1클릭 삽입, 커서/스크롤 위치 자동 유지)
   - **일반 악보 자동 변환기**: 인터넷에서 복사한 "윗줄 코드, 아랫줄 가사" 형태의 일반 텍스트를 붙여넣으면 ChordPro 형식으로 1초 만에 자동 변환

2. **연주자를 위한 핵심 편의 기능**
   - **조옮김(Transpose)**: `♭` / `♯` 버튼으로 반음 단위 실시간 Key 변경
   - **카포(Capo) 표시**: 원곡 키와 카포 프렛 위치 안내
   - **코드 운지법(Diagram) 팝업**: 악보 속 코드나 상단 코드 목록을 클릭하면 6줄 기타 프렛보드 운지법 SVG 다이어그램 표시
   - **자동 스크롤 (Auto Scroll)**: 연주 중 손을 떼지 않고 악보를 볼 수 있는 부드러운 자동 스크롤 (속도 1~8 조절, 스페이스바로 일시정지/재개)
   - **화면 꺼짐 방지 (Wake Lock)**: 연주 도중 스마트폰이나 태블릿 화면이 꺼지지 않도록 유지
   - **2단 펼쳐보기 (Two-column)**: 태블릿이나 PC의 넓은 화면에서 책처럼 2단으로 펼쳐보기 지원
   - **글자 크기 조절 (A- / A+)** 및 **전체화면 모드**

3. **악보 관리 및 데이터 보존**
   - 브라우저 로컬 저장소(LocalStorage)에 자동 저장
   - 기본 프리셋 악보 내장 (너에게 난 나에게 넌, Let It Be, 먼지가 되어)
   - JSON 파일로 악보 전체 백업(내보내기) 및 복원(불러오기) 지원

## 🐳 Docker 배포 (공유 Caddy Ingress 연동)

이 프로젝트는 **Nginx 대신 Caddy**를 사용하여 정적 파일을 서빙하며, `~/project1/infra/caddy`의 **공유 Caddy Ingress(caddy-docker-proxy)** 와 연동되어 자동 HTTPS 인증서 발급 및 리버스 프록시를 지원합니다.

### 1. 환경 설정 (.env)
`.env` 파일에 연결할 도메인을 지정합니다 (기본값: `guitar.ponytail.kr`):
```bash
cp .env.example .env
```

### 2. caddy 외부 네트워크 생성 (최초 1회 필요시)
```bash
docker network create caddy
```

### 3. 컨테이너 빌드 및 실행
```bash
docker compose up -d --build
```

- **도메인 접속 (공유 Caddy Ingress 연동 시)**: `https://guitar.ponytail.kr`
- **로컬 직접 접속**: `http://localhost:3000`

### 4. 컨테이너 종료
```bash
docker compose down
```
